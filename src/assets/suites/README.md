# Photos des suites

Chaque dossier correspond à une suite :

| Dossier  | Suite            |
|----------|------------------|
| `terre/` | La Suite Terre   |
| `eau/`   | La Suite Eau     |
| `metal/` | La Suite Métal   |
| `feu/`   | La Suite Feu     |
| `bois/`  | Le Cottage Bois  |

Pour ajouter des photos, il suffit de déposer les fichiers dans le bon dossier
(`.jpg`, `.png`, `.webp` ou `.avif`). Elles apparaissent automatiquement sur le site,
dans la fiche de la suite (« Explorer les suites »), au prochain déploiement.

- **Ordre** : alphabétique, en tenant compte des nombres (`01.jpg`, `02.jpg`… ou
  `1-chambre.jpg`, `2-salle-de-bain.jpg`). La première photo sert de couverture.
- **Taille** : idéalement 1600 px de large, en `.webp` ou `.jpg` compressé
  (moins de 400 Ko par photo) pour que le site reste rapide.
- **Retirer une photo** : supprimer le fichier.
